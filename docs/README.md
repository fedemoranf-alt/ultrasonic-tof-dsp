# Documentation

Background material and full write-up for this project.

## Publication

**A Reconfigurable Embedded Platform for Accurate Ultrasonic TOF Estimation**
E. A. Vargas Cabral, V. A. González Ayala, **F. D. Morán Fretes**
*2025 IEEE CHILEAN Conference on Electrical, Electronics Engineering, Information and
Communication Technologies (CHILECON)*, 2025.
📄 [`ieee-chilecon-2025.pdf`](ieee-chilecon-2025.pdf)

## Thesis

**Design and Implementation of a Low-Cost IoT-Based Ultrasonic Flowmeter** — final-degree
project, Universidad Católica "Nuestra Señora de la Asunción". Develops the
bandpass-sampling scheme, the envelope-derivative correlation method, the clock-jitter
analysis and the experimental validation summarised in the top-level README.
📄 [`thesis-ultrasonic-flowmeter.pdf`](thesis-ultrasonic-flowmeter.pdf) *(in Spanish)*
